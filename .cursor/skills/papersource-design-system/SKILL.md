# PaperSource design system

Read @docs/DESIGN-SYSTEM.md.

## When to Use

- Any storefront or admin UI
- Adding or restyling shadcn primitives
- Product cards, nav, drawers, forms

## Instructions

1. Feel: professional procurement catalogue — paper, grids, filing, whitespace. Not cartoon stationery or SaaS gradients.
2. Tokens: Ink Navy `#102A43`, Paper Green `#1F6B57` (sparse), Golden Ochre `#E6A329` (3%), Paper Cream `#F8F6F1`, white surfaces, Graphite `#20262E`, Slate `#667085`, Soft Grey `#E4E7EC`.
3. Mix: 70% cream/white + 20% navy/graphite + 7% green + 3% gold.
4. Fonts: Manrope headings, Inter body/UI.
5. Restyle shadcn before composing pages. Modest radius 4–8px. No default purple/zinc look.
6. Product card must show name, spec line, unit price + unit, tier hint, stock, Add to Cart, Add to Quote.
7. Cart and Quote List are visually different with independent counts.
8. Mobile bottom nav: Home · Shop · Search · Quote · Cart.
9. Motion sparingly. Honour `prefers-reduced-motion`.
10. Ghana address forms: phone first; no required US ZIP.
